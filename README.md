## 🔐 About the Project:

The Secure OTP Generator is a web-based application that creates random one-time passwords for security testing, authentication systems, or temporary access codes. Built with modern web technologies and featuring a stunning glassmorphism design, this tool provides both functionality and visual appeal.

Here's how it works:

Generate Secure OTPs: Click start to begin generating random numerical codes at regular intervals.

Real-time Display: Watch as new OTPs appear instantly in the large, easy-to-read display area.

History Tracking: The application automatically stores and displays the last 15 generated OTPs for reference.

Easy Control: Start and stop OTP generation with intuitive controls that provide instant feedback.

The project demonstrates modern CSS techniques, responsive design principles, and clean JavaScript architecture while providing a practical security tool.

## ✨ Features:

Real-time OTP Generation: Automatic generation of secure numerical codes at customizable intervals.

History Management: Tracks and displays the last 15 generated OTPs with automatic scrolling.

Glassmorphism UI: Modern, translucent design with backdrop blur effects and smooth animations.

Responsive Design: Fully responsive layout that works perfectly on desktop and mobile devices.

Copy-friendly Display: Large, monospace font display that's easy to read and copy.

Smooth Animations: Hover effects and scale transformations for enhanced user experience.

Secure Random Generation: Uses JavaScript's secure random number generation for cryptographically strong OTPs.

## 💻 Tech Stack:

Frontend: HTML5, CSS3, JavaScript (ES6+)

Frameworks & Libraries: Tailwind CSS for utility-first styling

Typography: Poppins font family for modern, clean text

Styling: Custom glassmorphism effects with backdrop filters and transparency

Design: Responsive layout with mobile-first approach

## 🚀 Getting Started:

To get the Secure OTP Generator running on your local machine, follow these simple steps.

Prerequisites
You'll need a modern web browser that supports CSS backdrop-filter and ES6+ JavaScript features.

Installation:

Clone the repository to your local machine:

git clone [https://github.com/YourUsername/secure-otp-generator.git](https://github.com/YourUsername/secure-otp-generator.git)

Navigate to the project directory:

cd secure-otp-generator

Ensure you have the background image:

Make sure bg.jpg is in the root directory for the background image to display properly.

Open the application:

Simply double-click on index.html or open it in your preferred web browser.

That's it! No build process, server setup, or dependencies required.

File Structure:

secure-otp-generator/
├── index.html          # Main HTML file
├── setout.css         # Custom styling (if any)
├── set.js             # OTP generation logic
├── bg.jpg             # Background image
└── README.md          # Project documentation

Contributing:

To contribute to the project, make your changes and then follow these Git commands:

Stage your changes:

git add .

git commit -m "feat: added OTP length customization"

Push your changes to the remote repository:

git push origin main

## 🎯 How to Use:

Using the OTP Generator:

Open the Application: Load the HTML file in your web browser

Start Generation: Click the "Start Generation" button to begin creating OTPs

Watch the Display: New OTPs will appear in the large central display area

Check History: View previously generated OTPs in the history box below

Copy OTPs: Click on any OTP to select and copy it for use

Stop Generation: Click "Stop Generation" to pause OTP creation

Resume Anytime: Click "Start Generation" again to continue where you left off
